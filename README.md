# Siri AI & Dynamic Island for Windows

Windows 桌面上的 Siri AI 助手与灵动岛个人实验项目，探索玻璃质感界面、动态交互与桌面体验。

## 持续更新
本项目将持续更新，逐步改进界面动画、功能联动、兼容性和稳定性。更新进展以提交记录、更新日志和 Releases 为准；具体功能和发布时间以实际发布为准。欢迎通过 Issues 反馈问题和建议。

## 目录
- `SiriAI/src/`：Siri AI 的 C# / WPF 源码。
- `DynamicIsland/`：灵动岛的 .NET 8 / WPF 源码及界面图片。
- `NOTICE.md`：非官方声明、第三方权利及许可说明。

## 当前发布范围
这是源码快照，尚未提供可直接安装的发行包。已排除私人对话、账号配置、密钥、日志、备份、本地模型和编译缓存。两个项目独立存放，当前发布不代表已验证两者的全部联动功能。

灵动岛项目目标为 `net8.0-windows10.0.19041.0`，需 Windows 及相应 .NET SDK。依赖在项目文件中声明。原项目使用的 Inter 字体暂未打包，需自行从原作者处取得字体和许可，并放入 `DynamicIsland/Fonts/`。

Siri AI 当前保留原始源码，需要另行配置 .NET Framework/WPF 构建引用。玻璃捕获辅助程序、语音模型、提示音、嵌入图像及 AI 服务配置未随本次源码快照分发，完整外观和功能可能依赖这些资源。源码仍含开发环境路径探测，其他电脑可能需要调整。构建及运行说明将继续完善。
